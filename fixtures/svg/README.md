# Static SVG import fixture

`phoenix-static-mark.svg` is an original, self-authored development fixture.
It combines a curve, primitive shapes, an internal gradient and a clip path.
It contains no text glyphs, image references or scripts. Dimensions: 1200×900 px.

This fixture is dedicated to the public domain under CC0-1.0.
It is not a customer logo, manufacturing approval or print-ready packaging.
