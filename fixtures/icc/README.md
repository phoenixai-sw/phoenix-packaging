# Synthetic CMYK transform fixture

`synthetic-cmyk-test.icc` is generated by `tests/geometry_pdf/make_test_icc.py`.
It is an original, deliberately synthetic ICC v2 CMYK output profile with
subtractive RGB/Lab lookup tables. We dedicate this fixture and generator to
the public domain under CC0-1.0: https://creativecommons.org/publicdomain/zero/1.0/

It demonstrates deterministic LittleCMS conversion, PDF ICC embedding, font
outlines, CMYK image channels, ink-limit checking and repeatable CI. It does
**not** describe a real printer, paper, ink, press characterization or ISO
printing condition. The production gate rejects this fixture even if someone
uploads it into the ICC registry. Free engine test PDFs remain visibly marked.

SHA256: `239f56c1c5b4be5d6bae17305d0d4aca4ea7db31b2b284ec6d28d210da0c104a`.

No third-party ICC is bundled. Administrators must supply a permitted actual
CMYK output ICC with its source and storage/PDF-embedding license before
registering a real output condition. Registration is separate from supplier
approval. ECI profiles are not redistributed here: their embedded copyright
permits use and embedding but restricts standalone distribution without
permission.
