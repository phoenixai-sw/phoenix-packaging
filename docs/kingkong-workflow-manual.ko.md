`37.5g × 4`의 산술 합계는 150g이다. 이번 사용자 지시는 300g 삭제와 개별 포장 표기 유지이며, 임의로 새로운 총중량 표기를 추가하라는 뜻으로 확대하지 않는다.

오리고기로 수정하더라도 `100%`와 `글리세린, 소금`을 함께 표시하는 의미는 별도로 확인되지 않았다. 참고 이미지의 성분 등록번호, 보증 성분량, 일일 급여량, 생후 개월 수, 원산지, 제조원·판매원·주소·전화번호·유통기한은 실제 상품 사실로 검증되지 않았다. 최종 검토에서 이 항목들을 확인된 사실과 구분한다.

원본 바코드 앞 12자리 `874265655238`로 계산한 체크디지트는 `1`이며 이미지의 끝자리 `5`와 다르다. 끝자리만 고쳐 임의의 상품 번호를 만드는 방식도 사용하지 않는다.

뒷면의 급여 안내와 성분 수치는 참고 이미지의 값을 재현하되 **샘플 기준 · 최종 확인 필요**라는 설명을 붙였다. 제조일, 유통 정보, 원산지, 제조원, 등록번호, 판매원은 최종 확인 대상으로 표시했다. 유효하지 않은 원본 바코드를 실제 코드로 생성하지 않았으며, 번호 확인을 위한 자리표시 텍스트를 사용했다.

최종 PDF의 보이는 텍스트 객체 20개를 저장된 장면 원문과 대조했다. `300g`과 `소고기`는 없고, 앞·뒤에 `37.5g × 4개입`과 오리고기 표기가 있다. 뒷면 원료 목록에는 원본의 글리세린·소금도 유지했다. 최종 출력의 저장 리비전은 37이다.

앞면의 크림색 원료 문구는 배경의 크림 곡선과 겹치지 않도록 x 23mm, y 184mm, 폭 120mm, 높이 10mm, 글자 20pt로 조정했다. 이는 실제 PDF를 렌더링해 발견한 대비 문제를 플랫폼 UI에서 고친 결과다.

### 4.6 AI 이미지 생성 및 재배치 - 완료

면 비율을 반영하는 서버 개선 후 운영 플랫폼 UI에서 참조 이미지를 사용한 AI 편집을 총 3회 실행했다. 세 작업 모두 성공했으며 요청 크기와 실제 결과는 모두 2432 × 3344px로 일치했다. 사용 모델은 `gpt-image-2.5-sunburst`다.

| 순서 | UI에서 실행한 작업 | 결과와 적용 |
| --- | --- | --- |
| 1 | 원본 앞면을 참조해 평면 배경 생성 | 골든리트리버와 네이비·오렌지 배경을 생성. 사진 속 봉투·주방과 글자를 제거하도록 요청 |
| 2 | 원본 뒷면을 참조해 평면 배경 생성 | 정보 텍스트를 올릴 넓은 네이비 영역, 하단 오렌지 띠와 작은 발자국. 이 결과를 최종 뒷면 배경으로 적용 |
| 3 | 첫 앞면 결과를 다시 참조해 수정 | 크림 곡선을 낮추고 뼈 모양 창의 테두리와 질감을 정리. 이 결과를 최종 앞면 배경으로 적용 |

배경에는 글자와 바코드를 생성하지 않도록 요청했고, 최종 앞·뒷면 PNG를 직접 열어 글자 없는 배경임을 확인했다. 상품명·중량·표시사항은 편집기 텍스트로 별도 관리했다. 이 과정을 다시 진행할 때는 처음 생성한 이미지도 참조 대상으로 선택할 수 있다. 이번 세 번째 작업이 실제로 첫 번째 결과 자산을 참조했는지 저장된 작업 기록과 대조했다.

원본 PNG의 SHA-256을 플랫폼 자산 기록과 비교하고 전체 이미지를 디코딩했다. 최종 앞·뒷면 모두 RGB PNG, 2432 × 3344px이며 240 × 330mm 배치 기준 약 257.39ppi다. 기본 검토 기준 300ppi에는 못 미치므로 이 경고를 유지한다. 생성 픽셀을 임의로 늘려 300ppi라고 표시하지 않는다.

각 작업은 10크레딧씩 한 번 정산되어 총 30크레딧을 사용했다. 대기 중 예약은 0, 반환은 0이며 세 작업 모두 제공자 실행은 1회였다. 제공자 비용 추정 합계는 약 USD 0.422665로 기록됐으나, 이는 플랫폼 크레딧이나 제공자 청구서 금액과는 다른 참고 값이다.

실제로 입력한 전체 프롬프트는 함께 보관한 `ai-prompts.ko.md`에서 확인할 수 있다. 요청·실제 크기, 결과 해시와 정산 기록은 `ai-readback-manifest.json`에 보관한다.

### 4.7 3D와 2D 면 이동 확인 - 완료

최종 이미지를 편집기에 적용한 뒤 3D 앞면을 확인하고 뒷면 2D 편집 화면으로 이동했다. 면별로 저장한 배경과 텍스트를 확인하는 단계다. 봉투가 충전됐을 때의 형태나 제작 공정까지 검증한 것은 아니다.

### 4.8 검토 PDF 생성 및 다운로드 - 완료

플랫폼 UI에서 최종 검수가 통과한 것을 확인하고 **검토용 PDF 만들기 · 무료**를 눌렀다. 최종 세 번째 출력에서는 앞면·뒷면·바닥 3면과 상품명·중량만 확인으로 체크했다. 원재료·알레르기·제조사·보관 정보는 미확인으로 유지했다. 사용자가 요청한 문구 수정과 실제 원재료 배합의 확인은 구분했다.

남은 검토 경고는 4개다. 앞면과 뒷면의 이미지 해상도가 각각 257.39ppi로 기본 300ppi 미만이고, 두 이미지가 각각 재단선 바깥 3mm 도련까지 연장되지 않았다. 페이지의 도련 영역에는 면의 바탕색만 자동 연장된다. 바닥 브랜드 상자를 조정해 접힘선 5mm 경고는 해결했다.

**파일 이력**에서 세 번째 파일의 성공 상태와 다운로드를 확인했다. 최종 작업 ID는 `bd6b1b4b-40bf-4d92-9965-e2c1782e4686`이다. 다운로드한 원본의 해시, 치수, 텍스트와 이미지 정보를 대조하고 4페이지를 모두 렌더링해 확인했다.

검수 통과는 현재 검토 출력이 가능하다는 뜻이다. 남은 해상도·도련 경고나 미확인 표시사항이 해결됐다는 뜻은 아니다. 이후 문구를 바꿀 때는 편집기에서 수정·저장하고 검수를 다시 실행한 뒤 새 검토 PDF를 만든다. 이전 파일을 최종본으로 혼동하지 않도록 출력 이력의 마지막 작업과 파일을 대조한다.

## 5. 240 × 330 × 120mm 구조 읽는 법

현재 플랫폼의 스탠드 파우치 데모는 다음과 같이 계산한다.

| 요소 | 현재 구조 |
| --- | --- |
| 앞면 | 240 × 330mm |
| 뒷면 | 240 × 330mm |
| 바닥 | 240 × 120mm |
| 바닥 가운데 접힘선 | 펼친 바닥의 60mm 위치 |
| 앞면·뒷면 글자 안전영역 | 왼쪽·위 15mm에서 시작하는 210 × 300mm 영역 |
| 바닥 글자 안전영역 | 사방 10mm를 제외한 220 × 100mm 영역 |
| 조립 참고 전개도 | 앞면, 바닥, 180도 회전한 뒷면을 연결한 240 × 780mm |

참고 도면에는 바닥 120mm라고만 쓰여 있어 펼친 치수인지 접힌 치수인지 독립적으로 확인되지 않는다. 이번 플랫폼 입력은 **펼친 바닥 120mm**라는 해석을 사용한다.

원본 도면의 둥근 모서리, 뜯는 홈, 지퍼 위치, 곡선 바닥과 실링 세부는 현재 데모의 직사각 패널 구조와 동일하지 않다. 사진에서 보이는 뼈 모양 투명창도 투명 소재 영역이나 화이트 잉크 분판으로 정의된 상태가 아니다. 3D는 같은 면과 텍스처를 조립한 확인 화면이며 충전 후 팽창·주름·소재 물성을 검증하는 모형은 아니다.

이번 작업에서는 원본 래스터 도면을 실제 제조 칼선 벡터로 추적하거나 재구축하지 않았다. 숨긴 참고 이미지와 현재 데모 구조를 구분해서 사용한다.

## 6. 최종 검토 PDF의 검증 결과

최종 플랫폼 PDF를 실제로 열어 아래 페이지 치수를 측정했다. 각 치수와 목표값의 차이는 0.01mm 미만이다.

| 페이지 | 역할 | 재단 크기: TrimBox | 전체 페이지: MediaBox |
| --- | --- | --- | --- |
| 1 | 앞면 | 240 × 330mm | 246 × 336mm |
| 2 | 뒷면 | 240 × 330mm | 246 × 336mm |
| 3 | 바닥 | 240 × 120mm | 246 × 126mm |
| 4 | 조립 참고 전개도 | 240 × 780mm | 240 × 780mm |

면별 1-3페이지는 재단선 바깥 사방 3mm 도련을 포함한다. 마지막 전개도는 조립 참고 페이지로 도련이 없다. 검토 PDF는 RGB 일반 PDF이며, 제조사 승인 제작 PDF, PDF/X, CMYK 또는 별색·화이트 잉크 출력으로 간주하지 않는다.

최종 파일에서 다음을 확인했다.

1. 앞·뒤·바닥·조립 참고도 4페이지와 면 방향이 정상이다. 조립 참고도의 뒷면 180도 회전은 현재 데모 조립 규칙이다.
2. `300g`과 `소고기`는 없으며 `37.5g × 4개입`과 오리고기 표기가 있다. 뒷면에 `오리고기 100%, 글리세린, 소금` 전체가 보인다.
3. 보이는 텍스트 객체 20개 모두 저장 원문과 추출 결과가 일치한다. 한글 폰트가 PDF에 포함돼 있고, 전 페이지 시각 검사에서 문구 잘림이나 원료 문구의 대비 문제가 없다.
4. 앞·뒷면 PDF에 포함된 이미지가 실제 2432 × 3344px이며 배치 기준 약 257.39ppi다. 원본 사진을 그대로 전체 면에 배치한 경우의 약 79-97ppi와 구분한다.
5. 유효하지 않은 바코드는 생성하지 않았고 확인 예정 영역만 있다. 원형 걸이 구멍도 추가하지 않았다.
6. 최종 리비전 37, 출력 작업 ID, 파일 SHA-256이 플랫폼 원본과 일치한다. 패키지 PDF 바이트는 수정하지 않았다.
