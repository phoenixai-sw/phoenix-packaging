# 검수 결과

2026-09-16. 플랫폼 기능·개발 검증과 외부 운영 승인을 구분한다. 실제 제조사 승인, 실제 PG 계약 또는 네이티브 IME 입력을 fixture나 DOM 입력으로 대체하지 않는다.

## 실행 근거

- 편집 장면 테스트5개와 Next.js 타입 검사·production 빌드 통과.
- 로컬 Python 회귀204개와 추가 복원 검증6개 통과. GitHub Linux/Python3.12 CI에서 전체210개, 편집기5개, 타입 검사·빌드가 모두 통과했다.
- 로컬 Chrome: 가입, 3면 스탠드 파우치 생성, 한글 줄바꿈 저장·재열기, EAN-13 삽입, 3D 면 선택, fixture AI2장 견적20·완료·적용, PDF 사전검사 오류 수정 후 출력 완료.
- 브랜드·상품·변형 생성, 연결 변경 미리보기·적용, 수동 편집 문구 보존, 결제 비활성·관리자403 확인.
- IAB 실제 화면:1440px 편집기·3D,390px 모바일 캔버스·도구/속성 탭·저장/출력 배치 확인.
- 로컬 API를 중단한 상태에서 한글을 수정하고 저장하여 연결 오류 표시·편집 보존 확인. API 재시작→재시도→저장 완료→재열기 성공.
- 같은 프로젝트를 두 브라우저 탭에서 열어 첫 탭 저장 후 두 번째 탭을 저장: 충돌 안내, 저장·출력 차단, 두 번째 편집 보관 확인. 서버 내용을 자동 덮어쓰지 않음.
- 실제 Supabase PostgreSQL 동시 예약: 잔액30에20짜리 요청 두 건 중 한 건만 예약, 다른 건 거절, 반환 후30/예약0. 모든 앱 테이블 RLS 확인.
- 작업 전 실제 클라우드 백업:9개 테이블·23개 레코드·4개 객체, 암호화 파일 및 격리 SQLite 값/FK/해시 복원 검사 통과.
- GPT Image2.5 Sunburst 마케팅 이미지3종과 Seedance2.5 영상1종 실제 제작·랜딩 적용. 영상1280×720/8.04초와1440/390 랜딩 재생·배치 검증은 [미디어 기록](media-production.md)에 있다.

실제 AI·업로드·PDF 결과는 아래 배포 실행 기록에 있다. 테스트 파일별 정산·운영 게이트 증빙은 [P2–P5 검증](p2-p5-validation.md)을 참고한다.

## 운영 조건

Toss 키·자동결제 계약, SMTP·도메인, 제조사 실제 자료와10건 검수, 운영 요금·환불·개인정보 정책이 필요하다. 현재 앱은 staging이고 실제 결제·제작은 비활성이다. Docker Compose 실기동과 네이티브 IME는 미실시다. 준비 방법은 [대표님 안내](owner-setup.ko.md)에 있다.

## 배포 실행 기록

코드 `ea068fe`의 웹·API production 배포가 READY이며, 애플리케이션 환경은 staging이다. GitHub main CI `35101744328`이 통과했다. 검수 계정·키·서명URL·원본 백업은 Git 제외 `.local`에만 보관한다.

- `scripts/smoke-platform.py`: 실제3종 프로젝트 저장/재열기/409·사전검사·PDF 완료. 검토 PDF는3면실링2페이지, 스탠드4페이지, 박스7페이지(각 면과 전개도), 첫 면160×230mm 오차0.01mm 이내, 한글 추출 통과.
- 4,627,704바이트 PNG(1400×1100)를20MiB 검역 경로로 직접 업로드. 완료 재요청은 같은 자산을 반환하며 비로그인401, 다운로드 해시 일치, 업로드 토큰 재사용 후 확정 파일 불변 확인.
- 실제 GPT Image2.5 Sunburst `quality=high`,1024×1024 생성1장·편집1장. 각10크레딧, 잔액30→10, 예약0. 동일 키 재요청은 같은 작업으로 응답하고 제공자 호출은 총2회였다. 제공자 요청ID·사용량·추정 원가US$0.115447을 DB에 기록했다(사용자 판매가격과 별개).
- 원본 이미지 해시 유지, 수정 이미지를 편집 장면에 적용/재열기, 한글 객체 유지, 이미지 포함 검토 PDF(2,087,104바이트) 생성·렌더 확인. 이 표본은 품질·연동 검수용이며 실제 상품의 표시 적합성을 뜻하지 않는다.
- 최신 백업40테이블·98행·11객체의 암호화·해시·FK 검사 통과. 원본 DB와 외부 네트워크를 쓰지 않는 복원 환경에서 기존 QA 계정 로그인, 프로젝트5개·리비전11개·자산4개·작업8개·PDF6개·원장5개를 다시 열었다. 장면의 이미지 연결도 확인했다.

기계 실행 증빙은 `.local/cloud-platform-smoke-result.json`, `.local/cloud-ai-provider-evidence.json`, `.local/backups/after-platform-20260916/verification.json`, `.local/recovery/after-platform-20260916/application-verification.json`에 있다. 실제 파괴적 장애 주입이나 제조사 제출은 수행하지 않았다.
