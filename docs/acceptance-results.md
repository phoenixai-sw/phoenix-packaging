# 검수 결과

2026-09-16 P0–P1 개발 시험판. 후속 범위의 미실시를 통과로 집계하지 않는다.

## 실제 실행 결과

- Python 통합 검증: backend19 + geometry/PDF32 = **51개 통과** (`.venv` Python3.14, ReportLab4.5.1).
- 편집 장면 단위검증: **4개 통과**. 안전영역·회전·면 구분·한글 보존·레이어 동작.
- Next.js 타입 검사와 배포 빌드 통과.
- Vercel 실제 환경: 가입/로그인 → Supabase 저장 → 한글/줄바꿈 수정 → 재열기 → 구버전409 → 비동기 출력 → 비공개 PDF 다운로드 통과.
- 실제 클라우드 PDF: 2페이지, 각 230×310mm, 한글 텍스트 추출 확인, 치수 차이0.01mm 이내.
- 브라우저: 랜딩·가입·빈 작업 공간·프로젝트 생성·텍스트 속성 편집·서버 저장 확인. 모바일 및1440px 랜딩 시각 확인.
- 샘플 PDF와 렌더링 증빙: `tests/geometry_pdf/artifacts/`.
- 클라우드 실행 스크립트: `scripts/smoke-cloud.py`. 생성 계정 비밀번호와 결과는 Git 제외 `.local/`에만 저장한다.
- Docker Compose와 실제 Windows IME 키 조합 시험은 미실시.

## 알려진 제한

제작용 PDF, 법정표시 적합성, 실제 바코드 판독·색상·제조 공차는 보증하지 않는다. 네이티브 동시편집 잠금 대신 서버 버전 검사를 사용하며, 다중 사용자 좌석 기능은 후속이다. 서버와 브라우저 글꼴 파일은 같은 SHA256으로 배포한다. SMTP 미설정 배포는 이메일 발송 완료로 표시하지 않는다.
