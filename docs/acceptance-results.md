# 검수 결과

2026-09-16. 플랫폼 기능·개발 검증과 외부 운영 승인을 구분한다. 실제 제조사 승인, 실제 PG 계약 또는 네이티브 IME 입력을 fixture나 DOM 입력으로 대체하지 않는다.

## 실행 근거

- 편집 장면 테스트5개와 Next.js 타입 검사·production 빌드 통과.
- 전체 Python 회귀204개 통과(229.91초). 이후 추가된 백업 복원 API 검증6개도 별도 통과했다. CI는 전체210개를 다시 실행한다.
- 로컬 Chrome: 가입, 3면 스탠드 파우치 생성, 한글 줄바꿈 저장·재열기, EAN-13 삽입, 3D 면 선택, fixture AI2장 견적20·완료·적용, PDF 사전검사 오류 수정 후 출력 완료.
- 브랜드·상품·변형 생성, 연결 변경 미리보기·적용, 수동 편집 문구 보존, 결제 비활성·관리자403 확인.
- IAB 실제 화면:1440px 편집기·3D,390px 모바일 캔버스·도구/속성 탭·저장/출력 배치 확인.
- 로컬 API를 중단한 상태에서 한글을 수정하고 저장하여 연결 오류 표시·편집 보존 확인. API 재시작→재시도→저장 완료→재열기 성공.
- 같은 프로젝트를 두 브라우저 탭에서 열어 첫 탭 저장 후 두 번째 탭을 저장: 충돌 안내, 저장·출력 차단, 두 번째 편집 보관 확인. 서버 내용을 자동 덮어쓰지 않음.
- 실제 Supabase PostgreSQL 동시 예약: 잔액30에20짜리 요청 두 건 중 한 건만 예약, 다른 건 거절, 반환 후30/예약0. 모든 앱 테이블 RLS 확인.
- 작업 전 실제 클라우드 백업:9개 테이블·23개 레코드·4개 객체, 암호화 파일 및 격리 SQLite 값/FK/해시 복원 검사 통과.
- GPT Image2.5 Sunburst 마케팅 이미지3종과 Seedance2.5 영상1종 실제 제작·랜딩 적용. 영상1280×720/8.04초와1440/390 랜딩 재생·배치 검증은 [미디어 기록](media-production.md)에 있다.

후속 배포의 실제 AI·업로드·PDF 결과와 최종 회귀 개수는 아래 배포 실행 기록에 추가한다. 테스트 파일별 정산·운영 게이트 증빙은 [P2–P5 검증](p2-p5-validation.md)을 참고한다.

## 운영 조건

Toss 키·자동결제 계약, SMTP·도메인, 제조사 실제 자료와10건 검수, 운영 요금·환불·개인정보 정책이 필요하다. 현재 앱은 staging이고 실제 결제·제작은 비활성이다. Docker Compose 실기동과 네이티브 IME는 미실시다. 준비 방법은 [대표님 안내](owner-setup.ko.md)에 있다.

## 배포 실행 기록

최종 배포 후 실제 실행 결과를 이 절에 기록한다. 검수용 계정·키·서명URL·원본 백업은 Git 제외 `.local`에만 보관한다.
