# King Kong Bites V2 - 실제 작업 화면으로 따라가는 패키지 매뉴얼

작성일: 2026-09-17

현재 상태: **실제 플랫폼 작업과 두 검토 PDF의 검증을 완료했다. 최종 파우치는 리비전 22·두 번째 출력, 박스는 리비전 23이다. 9페이지 PDF 매뉴얼에 실제 UI와 생성 이미지·최종 출력 미리보기를 담았다.**

이번 작업은 기존 오리스틱 디자인을 새 색감과 레이아웃으로 바꾸고, 걸이 구멍·지퍼·뜯는 홈·샘플 바코드·박스 윗면을 실제 플랫폼 기능으로 다루는 과정이다. 아래 화면은 실제 Phoenix Packaging UI를 캡처한 것이며, 배경 이미지는 플랫폼에서 생성한 원본이다. 패키지 PDF는 플랫폼 출력 원본을 사용하고 매뉴얼에서 새로 제작하지 않는다.

## 1. 무엇을 바꾸는 작업인가

| 대상 | V1에서 출발한 상태 | V2 작업 방향 |
| --- | --- | --- |
| 파우치 앞면 | 네이비·오렌지, 실사 강아지, 분리된 오리/스틱 텍스트 | 크림·짙은 자두색·코랄, 넓은 문구 영역, 새 강아지 배경과 편집 가능한 문구 |
| 파우치 뒷면 | 네이비 정보면, 크림색 바코드 예정 자리 | 크림 정보면으로 재구성, 검정 벡터 샘플 바코드를 별도 객체로 추가 |
| 상단 가공 | 직사각 데모 구조 | 헤더·지퍼·절취선·양쪽 U형 홈·원형 걸이 구멍을 구분해 설정 |
| 박스 | V1에는 별도 박스 프로젝트 없음 | 260 × 360 × 깊이 130mm 데모 박스 생성, 독립적인 **윗면** 편집 |
| 글자 굵기 | 일반 굵기 | 실제 400/700 글꼴을 선택해 브라우저와 PDF에 동일하게 반영 |

**유지하는 상품 정보:** King Kong Bites, 오리스틱, `37.5g × 4개입`, 원료 `오리고기 100%, 글리세린, 소금`. V1에서 삭제한 `300g`과 정정 전 `소고기`는 되살리지 않는다. `100%`의 기준과 실제 원재료 배합, 미확인 표시사항은 검증된 사실로 바꾸지 않는다.

## 3. AI는 배경을 만들고, 문구는 편집기로 관리한다

**AI 디자인 스튜디오**에서 작업 종류를 **표준 시안 만들기**, 시안 수를 1장으로 정했다. 앞면·뒷면·박스 윗면을 각각 선택해 프롬프트를 입력하고 **크레딧 견적 확인** 단계를 거쳐 생성했다.

이번 실제 색상 지시는 크림 `#FFF3DE`, 짙은 자두색 `#251536`, 코랄 `#F86848`, 작은 피스타치오 포인트 `#DCEF8F`다. 앞면에는 강아지와 뼈 모양 그래픽을 배치하되, 문구를 올릴 넓은 크림 영역을 요청했다. 뒷면에는 정보가 잘 읽히도록 거의 비어 있는 크림 면을, 박스 윗면에는 편집 가능한 브랜드 문구를 넣을 빈 중앙 장식을 요청했다.

세 요청 모두 사진 속 포장 목업 대신 **평평한 인쇄 배경**을 지정했다. AI가 글자·바코드·구멍·지퍼·절취선을 그리지 않도록 요청했다. 문구와 가공은 이후 플랫폼의 실제 객체·구조 설정으로 추가한다. 원래 고릴라 로고는 별도의 원본 자산이 없으므로 복제했다고 표시하지 않는다.

### 지금까지 확인한 생성 기록

| 면 | 생성 작업 | 실제 픽셀 | 상태 |
| --- | --- | --- | --- |
| 파우치 앞면 | `cee25d4c-8ba1-4150-9ded-4cd4d835f3dc` | 2432 × 3344 | 성공, 10크레딧 차감 |
| 파우치 뒷면 | `b32ecc07-dae0-46cd-89ab-a5e47cad2573` | 2432 × 3344 | 성공, 10크레딧 차감 |
| 박스 윗면 | `980e3075-f7d8-4916-bcbb-0bef9e3cd057` | 3840 × 1920 | 성공, 10크레딧 차감 |

실제 사용 모델은 `gpt-image-2.5-sunburst`이며 참조 이미지 없이 새 배경을 생성했다. 현재 확인한 3건은 요청 크기와 실제 크기가 일치한다. 파우치 배경은 재단 크기 240 × 330mm에 맞출 경우 약 257.39ppi, 윗면 배경은 260 × 130mm에 맞출 경우 약 375.14ppi다. **도련까지 이미지를 확장하면 최종 배치 ppi는 낮아지므로, 최종 PDF 검증값을 별도로 기록한다.**

### 도련 확장 과정에서 좌표 제한을 확인하고 비율을 유지해 조정했다

재단 크기와 같은 이미지에는 재단선 바깥의 그림이 없다. 처음에는 비율을 유지한 채 사방 3mm를 모두 덮도록 확대하려 했으나, 이미지가 허용 범위인 재단선 바깥 3mm를 넘는 좌표는 서버 검증에서 거절됐다. 앞서 시도한 파우치 y -4.125mm나 박스 x -3.1mm는 최종 저장값으로 사용하지 않는다.

다음은 UI에서 수정한 뒤 최종 저장 장면과 출력 PDF에서 대조한 실제 배치값이다.

| 대상 | x / y (mm) | 이미지 폭 × 높이 (mm) | 해당 배치의 계산 ppi |
| --- | --- | --- | --- |
| 파우치 앞·뒤 | -2.1818 / -3 | 244.3636 × 336 | 약 252.79 |
| 박스 앞·뒤 | -3 / -2.875 | 266 × 365.75 | 약 232.23 |
| 박스 윗면 | -3 / -1.5 | 266 × 133 | 약 366.68 |

그림이 도련을 전부 덮지 않는 가느다란 띠에는 면 바탕색 `#251536`을 사용한다. 파우치의 좌우 도련 끝 약 0.8182mm, 박스 앞·뒤 상하 약 0.125mm, 윗면 상하 약 1.5mm는 이미지가 아니라 면 바탕색으로 채워지는 구성이다. 최종 PDF 렌더링에서 빈 흰 틈 없이 바탕색이 채워진 것을 확인했다. 이미지와 바탕색의 경계가 완전히 같은 질감이라는 뜻은 아니며 이미지 도련 미연장·300ppi 미만 경고를 유지한다.

## 4. 문구를 바꾸고 실제 굵기를 적용했다

작업 방법은 면 선택 → 텍스트 선택 → 내용·크기·굵기·색·위치 수정 → 저장 상태 확인 순서다. AI 배경의 글자를 수정하는 방식이 아니라 독립적인 텍스트 객체를 편집한다. 굵기 700은 실제 굵은 글꼴 파일을 사용하며, 같은 상자에 들어가지 않으면 폭·높이·크기를 함께 조정한다.

아래 V2 문구는 실제 UI에서 변경하고 저장한 내용이며, 최종 장면과 PDF 원문을 대조했다. 전체 47개 텍스트 객체의 추가·내용·서식 변경은 [상세 수정 기록](kingkong-text-changes-v2.ko.md)에 정리했다. 이 수에는 숨긴 참고 문구 등의 변경도 포함되며 최종 PDF에 보이는 객체 수와는 다르다.

플랫폼에서는 **편집기 → 텍스트 변경 기록 → 확인할 면**에서 모든 면 또는 앞면·뒷면을 선택하고 저장번호·시간·이전/이후를 확인한다. 최근 100개 저장본을 비교하는 기능이며 저장 전 키 입력은 기록하지 않는다. 중간 저장본이 없는 구간에서는 확인 가능한 저장본 사이의 최종 차이를 보여준다. 전체 영구 이력이나 이전 버전으로 복원하는 기능으로 설명하지 않는다.

| 면·항목 | 확인된 V1 기준 | V2 최종값 |
| --- | --- | --- |
| 앞면 브랜드 | `King Kong` / `Bites`, 편집 가능한 워드마크 | `KING KONG BITES`로 변경 |
| 앞면 상품명 | `오리` / `스틱`, 각 98pt | 한글 `오리스틱`과 뼈 모양 그래픽 안의 두 줄 영문 `DUCK` / `STICKS`로 변경 |
| 앞면 슬로건 | `작은 한입, 큰 행복!` | `한 입에 시작되는 오늘의 행복.`으로 변경 |
| 앞면 원료 | `오리고기 100%`, 20pt | 원료 문구 유지. 최종 PDF에서 크림 바탕 위 자두색 굵은 글자로 확인 |
| 앞면 입수 | `37.5g × 4개입` | 문구 유지. 하단의 자두색 배경 위 크림색 글자로 확인 |
| 뒷면 상품명·원료 | 오리스틱 / `오리고기 100%, 글리세린, 소금` | 유지하고 원료 비율의 확인이 필요하다는 안내 추가 |
| 뒷면 정보 제목 | 제품 정보 / 참고 급여량 / 등록 성분량 / 급여·보관 시 참고사항 | 제품 한눈에 보기 / 급여 가이드 / 성분 가이드 / 함께 지켜 주세요 |
| 뒷면 바코드 영역 | 유효하지 않은 원본 번호 대신 예정 자리 | 기존 자리표시는 숨겨 보존. 파우치 샘플 바코드 X159 / Y274mm, 최종 흰 배경판 Y272 / 높이 35mm |
| 바닥 | 브랜드·슬로건, 오렌지 바탕 | 대문자 브랜드와 `오리스틱 · 오늘의 행복 한 입`으로 변경 |

## 6. 실제 샘플 바코드를 생성하고 PDF에서 판독했다

원본 번호 `8742656552385`는 체크디지트가 틀려 V1에서 추가되지 않았다. V2는 원본 번호를 임의로 고친 실제 상품코드 대신 **샘플 바코드** 기능을 사용했다. 실제 박스 번호는 `9520000000011`이며 좌표 x 165mm / y 302mm, 모듈 폭 0.33mm, 막대 높이 22.85mm로 추가했다. 샘플 라벨을 포함한 객체 전체 크기는 37.29 × 31.85mm다. 최종 저장 장면과 PDF 판독에서 일치한 것을 확인했다.

## 7. 검수·파일 이력·최종 출력 검증

최종 장면에서 면별 내용과 확인 항목을 검토하고 **검수와 출력**에서 검사한다. 사실 확인이 끝나지 않은 원료 배합·제조사 등의 항목은 임의로 체크하지 않는다. 무료 검토 PDF를 만든 뒤 **파일 이력**의 가장 최근 성공 작업에서 내려받는다.

## 8. 근거와 보관 위치

실제 화면은 `.local/kingkong-v2/evidence/`, 원본 AI 이미지는 `.local/kingkong-v2/images/`에 보관했다. `ai-readback-manifest.json`은 세 생성 작업·요청과 실제 크기·원본 해시를 연결한다. 앞·뒤 전체 프롬프트는 `prompts.json`, 윗면 프롬프트는 `top-prompt.txt`에 있으며, 세 작업의 저장된 전체 프롬프트는 manifest에서도 확인할 수 있다.

캡처 07과 10은 파일명에 quote가 들어 있지만, 실제 보이는 내용은 프롬프트와 **크레딧 견적 확인** 버튼이다. 해당 이미지를 견적 승인 또는 최종 결제 화면이라고 설명하지 않는다. 생성 성공과 차감은 완료 화면 및 저장된 작업 결과로 확인했다.

최종 파일은 `output/pdf/kingkong-pouch-review-v2.pdf`, `kingkong-box-review-v2.pdf`, `kingkong-workflow-manual-v2.pdf`다. 매뉴얼은 실제 작업 화면과 원본 생성 이미지·최종 출력 미리보기를 담은 9페이지이며, 150dpi로 전 페이지를 렌더링해 잘림·겹침·한글·캡션을 확인했다.
