# 파우치 가공 출력 엔진 검증

2026-09-18. 이 기록의 도면·승인은 격리된 시험 데이터다. 실제 제조사의 도면 승인·재질 적합성·입고 승인이나 실물 가공 시험을 수행했다는 뜻이 아니다.

## 지원 범위와 출력물

| 항목 | 구현 및 검증 범위 |
|---|---|
| 걸이 구멍 | 기존 허용 영역 안의 원형, 지름 4~10mm. 앞면 물리 좌표를 뒷면에 반사한다. |
| 좌우 개봉 노치 | 기존 유효 치수 범위의 V 또는 U 모양. 실제 외곽 직선의 해당 구간을 제거하고 벡터 경로를 삽입한다. |
| 개봉부 | 헤더와 개봉 위치를 별도 가공 문서에 표시한다. 개봉 참고선을 절취선·미싱 가공 명령으로 간주하지 않는다. |
| 지퍼·실링 | 지퍼 중심선, 부착 대역, 등록 실링 영역을 별도 가공 문서와 좌표 JSON에 기록한다. |
| 등록 구조 | `StructureDefinitionV2.feature_policy=pouch-finishing-v1` 및 고정 `finishing` 값. 분리 삼방 면과 제한된 직사각 등록 파우치 전개를 지원한다. |
| 아트 | 실제 구멍·노치 경로로 그림을 녹아웃한다. 흰 도형을 덮지 않으며 외곽 도련은 보존한다. |

가공이 있는 ICC CMYK 번들에는 기존 `production.pdf`, `cut.pdf`, `fold.pdf`, `preview.png`, `preflight.json`, `manifest.json`에 `process.pdf`, `finishing.json`을 추가한다. 제작 작업에는 기존 `job-ticket.json`, `job-ticket.pdf`도 포함되어 총 10개 파일이다. 무료 엔진 시험은 8개 파일이며 PDF마다 제작 사용 불가 표기를 넣는다. 가공 없는 과거 출력은 기존 시험 6개/제작 8개 파일 계약을 유지한다. 기본 RGB 어댑터의 가공 제작 차단도 유지한다.

`cut.pdf`는 외곽·원형 타공·노치, `fold.pdf`는 접힘, `process.pdf`는 가공 배치 안내만 담는다. 가공 종류, 면, 좌표, 물리 명세 해시를 `finishing.json`에 저장하고 나머지 파일과 함께 manifest SHA-256으로 검증한다. CUT 이름의 별색 분판을 만든다고 주장하지 않는다.

## 승인 및 불변성

제작에는 기존의 비데모 템플릿/프로필, 동일 제조사·재질, 정확한 승인 치수, 불변 리비전, 전 면·표시사항 확인, ICC 원본, 프로필 능력 검사를 모두 통과해야 한다. 여기에 다음 조건을 추가했다.

1. 프로필이 `finishing_delivery=separate_process_pdf_v1`을 명시한다.
2. 템플릿 `approved_finishing`에 현재 구조의 물리 해시와 실제 가공값을 저장한다.
3. 승인 증빙의 `finishing_hash`가 정규화된 `approved_finishing` 해시와 일치한다.
4. 제작 직전 및 저장 후 게시·크레딧 확정 직전에 승인 상태를 다시 확인한다.

물리 해시는 DB 버전 식별자나 화면 구멍 ID에 의존하지 않는다. 면 치수·전개 배치·실링/가공 영역·실제 구멍 좌표가 바뀌면 달라진다. 등록 구조의 제작 과금 지문도 비활성 슬라이더 값과 구멍 ID를 제외한다. 정의 및 출력 스냅샷은 별도 해시로 전체 원문을 계속 동결한다.

관리자가 프로젝트에서 가공값을 가져오는 동작은 값 복사다. 사용자 체크나 정상 도면 계산만으로 제조사 승인을 생성하지 않는다. 등록 정의 가공값은 구조 적용 경로에서 장면으로 복사하며 이후 장면의 다른 가공값은 거부한다.

## 실제 검증

- 기존 `tests/geometry_pdf` 전체 231개 통과 후 추가 경계/판독/지문 테스트를 실행했다. 최종 신규 가공 집중 `tests/geometry_pdf/test_print_finishing.py` 22개가 모두 통과했다. 앞선 전체 실행과 중복을 제외한 이 범위는 238개다.
- 최종 PDF 스트림을 읽어 변환 행렬을 적용한 실제 직선·3차 Bézier 좌표를 동결 기하와 0.01mm 이내로 비교한다. 누락·추가 경로와 중복 CUT을 거부한다.
- 원형은 네 개, U 노치는 두 개의 1/4 타원 Bézier로 작성한다. 지원하는 최대 반경 5mm의 원형 근사 오차는 0.0014mm 미만이다.
- 지름 6mm, U 노치 3×4mm, 앞면 구멍 X65/뒷면 X95, 전개 회전 후 X65·Y16/504 좌표를 시험했다. V 노치도 독립 시험했다.
- 실제 래스터 판독으로 구멍·노치 안의 비인쇄 영역과 주변 아트, 외곽 3.175mm 도련 보존을 검사했다. 300dpi로 렌더한 최종 가공 아트의 EAN-13 샘플 판독도 통과한다. 실물 인쇄 바코드 등급은 검증하지 않았다.
- 접힘선과 구멍/노치/지퍼 대역의 교차, 등록 실링과 지퍼의 충돌, 내부 연결선을 외곽 노치로 바꾸는 시도를 차단한다. 60×80mm 최소 규격의 구멍만/헤더만 출력도 시험한다.
- 격리된 worker에서 승인된 가공 출력 40크레딧, 구멍 위치가 바뀐 별도 승인 버전 40크레딧, 기존 가공 복원 0크레딧을 확인했다. 저장 직후 승인 철회·증빙 해시·재질·치수 변경은 게시되지 않고 예약이 반환되며 과금 확정이 0이다.

로컬 실제 샘플: `output/pdf/pouch-finishing-samples/face-pages/`, `registered-net/`. 각각 아트/CUT/FOLD/PROCESS PDF와 Poppler 110dpi PNG를 저장했다. 총 8개 PDF, 12페이지를 전수 시각 확인했다. 한글 윤곽선·원형 타공·양측 노치·가공 범례·앞뒤 반사를 확인했으며 시험용 ICC와 제작 사용 불가 표기를 유지했다. `verification.json`에 파일 해시와 실제 PDF 측정 결과를 보존했다. 이 폴더는 로컬 QA 산출물이며 Git 문서의 첨부로 배포되지 않는다.

## 계속 차단하는 조건

임의 SVG 칼선, 원형 이외의 걸이 구멍, 패키지 외곽 둥근 모서리, U/V 이외 노치, 내부 패널을 자르는 노치, 미싱·레이저 절취 조건, 곡선 접힘, PDF/X 인증, 별색/화이트판/오버프린트는 이번 출력 범위가 아니다. 제조사 증빙·승인 가공값·재질·치수·프로필이 없거나 다르면 제작은 계속 차단한다. 무료 시험 성공은 제조 승인과 무관하다.
