## 발견한 문제와 보완

1. 결제 승인 응답이 보류·실패여도 성공을 표시할 수 있었다. 서버 주문 상태가 `paid`인 경우만 완료로 표시한다.
2. 만료·취소된 구독 객체 때문에 같은 요금제 재가입이 막혔다. 실제 활성 구독 여부로 재가입과 요금제 변경을 구분한다.
3. 불확실한 PG 취소 결과를 환불 완료로 표시할 수 있었다. `refunded`인 경우만 완료로 표시한다.
4. 유효한 팀 초대에 상태 값이 없어 빈 셀이 표시됐다. 수락 대기와 만료일을 표시한다.
5. 다른 작업 공간의 최신 프로젝트가 100개 이상이면 권한 있는 오래된 프로젝트가 목록에서 사라졌다. 권한 필터를 조회 제한보다 먼저 적용한다.
6. 최소 규격의 초기 텍스트가 안전영역 밖에 배치될 수 있었다. 크기에 맞게 초기 배치를 조정한다.
7. 기본 바코드 위치가 기존 글자와 겹쳐 출력을 막을 수 있었다. 서버에서 여백·충돌을 확인하고 배치한다.
8. 제작 출력 실패에 사용할 수 없는 재시도 버튼을 표시하고 일부 종료 상태를 작업 중으로 표시했다. 출력 종류와 종료 상태에 맞게 안내한다.
9. 초대 링크를 분실하면 만료일까지 재초대가 막혔다. 소유자가 대기 중 초대를 취소한 뒤 다시 초대할 수 있게 한다.

새 바코드 배치 API도 기존 Scene 모델을 통과하도록 하여 잘못된 입력이 서버 500 대신 입력 오류 422로 처리되게 했다. 작은 포장에 들어가지 않는 지나치게 긴 문구는 잘라 저장하지 않고 명확한 넘침 오류로 차단한다.

실제 PG 승인·환불, 외부 팀원 초대 전송·수락, 제조사 승인 등록·제작 출력은 이번 운영 점검에서 실행하지 않았다. 상태 처리·권한·차단 동작은 별도의 회귀 테스트로 검증한다.
