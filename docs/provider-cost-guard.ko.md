# API 비용 제한과 운영 예산 표시

이미지 제공자 사용료와 고객 크레딧 원장은 별도다. 고객에게 실패 크레딧을 반환했더라도 실제 또는 미확인 제공자 비용을 지우지 않는다.

| 환경 설정 | 기본값 | 의미 |
| --- | --- | --- |
| `AI_DAILY_UNIT_LIMIT` | 30 | 기존 UTC 일일 호출 예약 상한 |
| `AI_DAILY_COST_LIMIT_USD` | 10 | UTC 하루의 기록 비용 + 미확인 요청 허용액 + 다음 요청 허용액이 넘으면 호출 전 차단 |
| `AI_REQUEST_ALLOWANCE_USD` | 2 | 응답 전/사용량 미확인 요청 1회에 잡아두는 보수적 추정액 |
| `AI_MONTHLY_BUDGET_ALERT_USD` | 100 | 전체 조직의 월 누적 추정비용에 대한 관리자 화면 알림 기준 |

위 기본값은 API 한 장의 가격이 아니라 초기 운영 보호 설정이다. 모델·크기·품질과 실제 측정 비용을 확인해 운영자가 서버 환경에서 조정한다. 과거 요청의 허용액은 요청 당시 값으로 보관하며 이전 기록에 값이 없으면 현재 보수적 허용액을 적용한다. 고객의 결제 가격·차감 크레딧을 바꾸지 않는다.

호출 예약은 전체 조직이 공유하는 당일 DB 행을 잠근 뒤 비용과 호출 수를 판단한다. 동시에 다른 조직이나 worker가 호출하더라도 미확인 허용액을 빼고 계산하지 않는다. 사용량이 오면 기록된 비용으로 대체한다. 타임아웃으로 결과가 불명확한 요청은 허용액을 유지한다. 실제 호출 전 취소가 확인된 경우만 0으로 처리한다. 한도를 넘으면 대기 이미지의 크레딧 예약을 반환하고 작업 오류와 감사 이벤트를 남긴다.

관리자 원가 화면은 기록된 비용, 미확인 요청 수·허용액, 일일 제한과 월간 경보를 구분한다. 알림은 이 화면에서 제공하며 이메일·문자 발송은 포함하지 않는다.

**정확한 최종 청구액 상한을 보장하지 않는다.** 제공자 실제 비용이 호출 전 추정액보다 크거나 외부에서 같은 API 키를 사용하면 그 비용을 사전에 알 수 없다. 초과 비용이 보고되면 후속 호출을 막는다. 제공자 계정 자체 예산도 별도로 관리해야 한다. fixture는 유료 비용 제한 대상이 아니다.
