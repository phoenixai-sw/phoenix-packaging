# 원문 요구사항 완료 추적표

2026-09-18 기준. [최초 작업지시서](../Phoenix_Packaging_Codex_작업지시서.md)의 P0~P5·주요 범위·AC01~32를 추적한다. **PR9까지 운영 웹/API 배포와 DB0017 이행을 완료했다.** PR9 병합 커밋 `21e5070c14f1aa377aab67a7e68eec7d177a97fb`는 CI 검증본 `a40f38e`와 내용이 같다. PR8 `7f4e81f`의 운영 ZIP12파일·9.8MiB 검증과 배포 전 백업41테이블·293행·33객체의 격리 앱 재열기는 이전 단계의 증거이며, PR9 배포 후 별도 운영 QA 글꼴·SVG·출력3건/8페이지와63테이블·338행·39객체의 새 논리 백업/격리 앱 재열기도 통과했다.

**계약·인쇄 엔진·보관/지원·서비스 주문·정책·글꼴·성과 측정 코드도 PR9 운영 배포에 포함됐다. 원문 전체 완료가 아니다.** [CI35274845908](https://github.com/phoenixai-sw/phoenix-packaging/actions/runs/35274845908)에서 전체 Python844개·프런트78개·타입 검사·Scene/OpenAPI/TS drift·production 빌드가 통과했다. 웹/API main 배포 모두 성공, 비공개 버킷 MIME 추가·전체 RLS·실행 플래그 OFF 유지와 고객 데이터 보존을 확인했다. 데이터 비교의 3개 차이는 작업 heartbeat·지갑 잠금 제어 필드였다.

‘운영 구현’은 해당 코드가 운영에 반영됐다는 뜻이며 모든 운영 UI·외부 서비스·실물 검증까지 통과했다는 뜻은 아니다. ‘미실시’는 통과로 세지 않는다. 외부 PG·실물 제조와 아래 지원 제한이 해소되기 전에는 유료 시험 운영 가능이나 원문 전체 개발 완료로 보고하지 않는다.
