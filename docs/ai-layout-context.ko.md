# AI 생성 지시에 브랜드와 편집 배치 반영

원문 §9의 포장 종류·면 비율·브랜드 색상·독립 텍스트 영역을 이미지 견적 시 서버에서 가져온다. 운영 배포와 실제 유료 생성 품질 확인은 별도 기록한다.

- 프로젝트에서 선택한 포장 종류와 면 크기·비율을 사용한다.
- 연결된 브랜드의 유효한 HEX 색상만 복사한다. 브랜드명이 이미지에 그려질 문구로 전달되거나 로고가 자동으로 새로 생성되지 않는다.
- 현재 면에서 표시·인쇄되는 글자와 바코드의 회전 외곽에 2mm 여백을 더해 비워 둘 영역으로 전달한다. 실제 상품 문구와 바코드 번호는 이 문맥에 넣지 않는다. 객체가 없으면 안전영역 중앙 60%를 제안한다. 영역이 많으면 모두 포함하는 외곽으로 묶는다.
- 견적에 실제 제공자 프롬프트·컨텍스트·버전을 고정한다. 견적 이후 브랜드 색상이 달라져도 이미 예약한 요청이 바뀌지 않는다. 새 값은 새 견적에 반영된다.
- 배경 생성은 `packaging-background-v2`, 일반 수정은 `packaging-reference-edit-v2`다. 기존 견적과 글자 제거의 `packaging-remove-text-v1` 보존 규칙은 유지한다. 제거 영역 밖 이미지를 보존하는 서버 합성에도 변화를 주지 않는다.
- 원본 상품 사진과 로고는 별도 이미지 객체다. 생성 지시는 상품 외형 변경을 요청하지 않은 경우 제품을 새로 그리지 않도록 명시한다. 모든 기존 이미지를 새 참조 이미지로 외부 전송하지 않는다.

이 값은 생성 지시에 반영되는 조건이다. 모델이 여백·색을 정확히 지켰다는 검증 결과나 최종 제조 승인으로 표시하지 않는다. 실제 결과 확인 후 글자·바코드를 편집 객체로 적용해야 한다. 이번 개발 검증은 외부 유료 API 호출 없이 진행한다.

프롬프트 구조는 목적·구도·배치 제약과 수정 시 유지할 요소를 명확히 하라는 [OpenAI 이미지 프롬프트 문서](https://developers.openai.com/api/docs/guides/image-prompting)에 맞췄다. 기존 Images API 계약과 사용자 지정 Sunburst/Flare 선택은 [공식 생성 명세](https://developers.openai.com/api/reference/cli/resources/images/methods/generate)를 유지한다.
