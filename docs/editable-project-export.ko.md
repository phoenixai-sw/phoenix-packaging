# 편집용 프로젝트 ZIP

2026-09-18 · 구현 및 로컬 통합 검증 중. 운영 배포·실제 ZIP 다운로드 검증 결과는 별도로 기록합니다.

편집기 **검수와 출력 → 편집용 프로젝트 ZIP · 0크레딧**에서 요청합니다. 현재 편집 내용을 먼저 서버에 저장하고 그 저장본으로 파일을 준비합니다. 저장 실패, 충돌 또는 읽기 모드에서는 새 파일을 요청하지 않습니다. 제조용 검수 통과나 추가 권리 동의 체크는 필요하지 않습니다.

1. 편집 권한이 있는 창에서 버튼을 누르고 대기·준비 상태를 확인합니다.
2. **준비 완료 → 편집용 프로젝트 ZIP 다운로드**를 누릅니다. 완료된 파일에는 저장본 번호·이미지 수·글꼴 수·파일 크기가 표시됩니다.
3. 창을 닫았다면 **파일 이력 보기**에서 다시 확인합니다. 실패한 편집용 ZIP과 검토 PDF는 **파일 준비 다시 시도**를 사용할 수 있습니다. 다른 탭에서 편집 중이면 해당 편집창에서 요청하거나 그 창의 편집 권한을 반납해야 합니다.

| 포함 자료 | 용도 |
|---|---|
| `scene.json` | 모든 면의 객체·문구·위치·스타일·자르기·숨김 상태를 보존한 Phoenix 편집 데이터 |
| `project.json`, `geometry.json` | 해당 저장본의 프로젝트 정보와 도면 기하 |
| `assets/`, `assets.json` | 연결된 원본 이미지와 접근 가능한 파생 이미지의 원본 연결 정보. 자르거나 재압축하지 않음 |
| `fonts/` | 재배포가 허용된 사용 글꼴과 라이선스 안내 |
| `manifest.json`, `README.ko.txt` | 파일 목록·해시·리비전·읽는 방법·권리 안내 |

제작 PDF, Illustrator 또는 Photoshop 형식이 아닙니다. 앱에 ZIP을 다시 가져오는 기능, 전체 계정 백업, 모든 리비전 이력은 포함하지 않습니다. JSON과 원본 파일을 다루는 후속 편집 연동을 위한 자료입니다.

이미지·글꼴의 기존 사용 권한은 그대로이며 다운로드로 새 권리가 생기지 않습니다. 샘플 바코드, 낮은 원본 해상도, 합성 도련, 미승인 제조 조건도 그대로 남습니다. 제조사 전달용 인쇄 파일은 별도의 검수·제작 출력 절차를 확인하세요.
