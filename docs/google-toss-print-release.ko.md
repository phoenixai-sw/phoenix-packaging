# 2026-09-17 인증·결제·출력 변경 검증

사용자 요청의 세 항목을 같은 변경으로 구현했다. 기존 운영 버전은 Google Cloud 허용 원본 저장과 실제 로그인 확인을 끝낸 뒤 교체한다. 새 코드만 먼저 운영 도메인에 연결해 기존 로그인을 끊지 않는다.

## 반영 범위

- Toss 공식 문서 MCP 등록 및 stdio 조회. 지정 AI브릿지 네 파일의 승인·취소·웹훅·동기화 동작을 기존 Python 서버와 불변 원장에 이식했다. [이식 상세](toss-payment-port.md).
- Google 단독 로그인, 공식 서명 검증, nonce·CSRF·세션 회전, `ADMIN_EMAILS` 운영 권한. 비밀번호·메일 인증·복구 및 SMTP 모듈을 제거했다. 고객 팀 초대는 링크를 직접 공유한다. [인증 상세](auth-google.md).
- GS1·ISO 공개 자료, 한성피엔지·패커티브·레드프린팅 공개 입고 조건 조사와 [기본 규격표](basic-print-specifications.ko.md). 실제 PDF의 3mm 도련·재단 박스·글꼴 포함·바코드 판독을 저장 전에 검사한다.
- 독립 검토에서 발견한 상향 환불 후 유료 팀 권한 잔존, Google 스크립트 로딩 재시도, 프록시 공통 로그인 횟수 제한을 수정했다.

## 배포 준비

- 기존 로컬 설정에서 Google Client ID와 관리자 허용목록을 가져와 로컬 및 Vercel 암호화 환경에 연결했다. 새 Google 비밀키·메일 서비스는 필요 없다.
- 로컬 DB는 `0007_google_auth`이며 새 Google 버튼 표시를 브라우저에서 확인했다. 실제 Google 인증 완료는 아직 검증하지 않았다.
- 운영 DB는 `0006_direct_uploads`를 유지한다. 변경 전 배포 코드 `6da6c0e`로 40개 테이블·98개 행·11개 객체를 암호화 백업하고 격리 복원·해시 검사를 통과했다. 프로젝트 6개·사용자 2개, public 41개 테이블 RLS를 확인했다.
- `0007_google_auth`는 기존 비밀번호·메일 토큰·세션을 제거한다. 새 배포 준비 후 적용하며 계정 소유자는 Google로 다시 로그인한다. 과거 자격 증명을 되살리는 자동 downgrade는 제공하지 않는다.

## 남은 실제 서비스 확인

Google Cloud의 기존 `aibridge-web` 클라이언트에 운영 사이트와 로컬 두 원본을 입력하고 저장 직전까지 준비했다. OAuth 허용 범위 확장에 대한 브라우저 도구의 실행 시점 확인을 요청했으며 답변 대기 중이다. 저장 후 실제 로그인과 운영 배포 전환을 이어간다.

Toss 테스트 키는 참조 설정에서 확인했지만 같은 상점 MID와 자동결제 계약은 미확인이다. 실제 카드 등록·승인·취소 또는 라이브 청구를 수행했다고 기록하지 않는다. 결제 비활성 설정을 유지한다.

공개 규격에 따른 검토 PDF 검증과 제조 승인·CMYK·PDF/X·윤곽선·실물 바코드 등급은 구분한다. 제조사 자료 요청문은 폐기했으며 공개 규격만으로 실제 제조 승인을 생성하지 않는다.
