# King Kong Bites V2 실제 문구·서식 변경 기록

이 문서는 운영 플랫폼 UI에서 저장된 실제 장면을 비교한 기록입니다. 생성형 이미지는 배경 그림이며, 아래 문구는 편집기의 텍스트 객체로 저장되어 PDF에서 선택·추출할 수 있습니다. DB는 READ ONLY 트랜잭션으로 조회했고, 이 문서를 만들면서 디자인 데이터·크레딧·출력 작업을 변경하지 않았습니다.

메뉴별 진행 화면과 결과 이미지는 [실제 작업 매뉴얼](kingkong-workflow-manual-v2.ko.md)에서 확인할 수 있습니다. 이 문서의 `C:/...` 링크는 작업한 PC의 파일을 가리키며, PDF 결과물은 별도로 제공합니다. GitHub에서 해당 로컬 파일이 직접 열리지는 않습니다.

- 수정 전 캡처: 2026-09-17 19:45:54 KST — 두 프로젝트 모두 초안 리비전 5.
- 최종 캡처: 2026-09-17 20:16:37 KST — 파우치 리비전 22, 박스 리비전 23.
- 비교 기준은 캡처한 초안과 저장 리비전입니다. 모든 키 입력의 녹화 기록은 아니며, 이전 버전에 없던 중간 리비전을 추정해서 복원하지 않았습니다.
- “굵게”는 Noto Sans KR 700 실제 폰트, 일반은 400입니다. 최종 PDF에서 두 글꼴 임베딩을 확인했습니다.

## 제품 정보와 사용 범위

제품명·중량·원료·급여 안내는 사용자가 제공한 내용을 배치한 검토용 표시 초안입니다. 제조원·원산지·등록번호는 최종 확인 대상으로 남아 있습니다. “오리고기 100%” 문구와 글리세린·소금 등의 원료 표기는 실제 제품의 배합·원료 설명과 대조해 확정해야 하며, 이 디자인 작업이 제품 내용이나 인증을 검증한 것은 아닙니다. 인증 체크나 정식 바코드 소유권 확인은 수행하지 않았습니다.

원본 참고 이미지의 `300g` 제외 및 `소고기 100%`를 `오리고기 100%`로 바꾸는 요청은 V1 작업에서 이미 반영했습니다. 흐름은 **원본 참고 이미지 → V1에서 요청 문구 반영 → V2에서 유지**입니다. 이 문서의 V2 수정 전 캡처에도 이미 `37.5g × 4개입`과 `오리고기 100%`가 있으므로, 이를 V2에서 새로 바꾼 문구로 기록하지 않았습니다. 아래 표에서 같은 문구가 양쪽에 있으면 글꼴·색상·위치만 바뀐 항목입니다.

두 PDF는 제조사 미승인 검토용입니다. 샘플 EAN-13 `9520000000011`은 `barcode_usage=sample`, `barcode_owned=false`이며 `SAMPLE / 검토용` 표시가 있습니다. 디지털 판독 확인은 실물 인쇄 판독이나 정식 상품 번호 발급·소유권을 뜻하지 않습니다. 샘플 바코드와 미검증 파우치 가공은 생산 출력에서 차단됩니다.
