# 기본 규격표와 공개 근거

조사일: **2026-09-17**. 공개된 공식 자료를 직접 대조한 검토 기준이다. 업체별 상품·공정이 다르므로 수치를 합쳐 보편적 제조 승인 규격으로 취급하지 않는다. 유료 표준 전문을 구매하거나 인증을 받았다는 의미도 아니다.

현재 기본 검토 프로필은 `phoenix-basic-review-v1`이다. 새 검토 작업은 이 버전을 불변 스냅샷에 기록한다. 과거 버전이 없는 작업은 기존 완성 치수 페이지를 유지한다. 제작 승인 등록 여부와 관계없이 기본 검토를 실행할 수 있다.

## 3. GS1 바코드 적용 범위

[GS1 Sweden 공식 크기표](https://gs1.se/en/guides/how-to-guides/size-guide/)의 **소비자 포장 EAN-13** 수치는 X 최소/권장/최대 0.264/0.330/0.660mm, 바 높이 18.28/22.85/45.70mm, 공백 11X/7X다. 바 높이는 숫자 표시 영역을 제외한다. 같은 표의 외포장 EAN-13은 최소 X=0.495mm·바 높이 34.28mm로 범위가 다르므로 현재 소비자용 프로필을 물류 외포장으로 해석하지 않는다.

[GS1 Ireland 공식 EAN-13 안내](https://www.gs1ie.org/standards/data-carriers/barcodes/ean-13/)는 기준 폭 37.29mm, 기준 전체 높이 27.85mm와 80~200% 범위를 설명한다. 엔진은 95개 모듈 + 양쪽 공백 18개 = 113X 폭을 사용한다. 기준 X=0.330mm에서 폭은 37.29mm다. 숫자 표시 영역은 별도 5mm를 두며, 크기·공백·체크 숫자·디지털 판독을 검증한다. 이것이 GS1 전체 심벌 도안 인증, 발급 번호 소유 확인, 인쇄 대비·번짐·등급 검증을 대신하지 않는다.

전체 최신 GS1 General Specifications 전문을 모두 검증했다고 주장하지 않는다. 여기서는 접근 가능한 GS1 공식 회원기관의 공개 크기 안내를 근거로 한다. 최소값 아래 임의 축소나 작은 면적에 대한 예외 승인은 구현하지 않는다.

## 4. ISO 12647과 PDF 입고 형식의 차이

- [ISO 12647-2:2013 공식 공개 개요](https://www.iso.org/standard/57833.html)는 4색 오프셋 인쇄의 색 분해·교정·인쇄판·인쇄물 등 공정 조건을 다룬다. 포장용 판지를 포함하지만 모든 PDF에 공통으로 도련 3mm 또는 이미지 300ppi를 정하는 문서라고 해석하지 않는다.
- [ISO 12647-6:2020 공식 공개 개요](https://www.iso.org/standard/75219.html)는 플렉소 인쇄의 색 특성·목표값·공정 제어를 다룬다. 라벨·상자·연포장이 적용 예다. 현재 RGB 검토 PDF를 이 공정 표준 인증 결과로 표시하지 않는다.
- [ISO 15930-7:2010 공식 공개 개요](https://www.iso.org/standard/55843.html)는 PDF 1.6 기반 PDF/X-4 교환을 다룬다. PDF/X에는 색 관리·출력 조건 등 별도 요구가 있으므로 PDF 헤더 버전만 맞추는 것으로 충족하지 않는다. PDF/X-4를 단순히 CMYK 전용 형식이라고 부르지 않는다.

공개 개요 범위만 조사했으며 유료 전문의 세부 공차·규정 준수나 ISO 인증을 주장하지 않는다. 업체가 명시하지 않은 PDF/X 버전을 ISO 12647에서 유추하여 채우지 않았다.
